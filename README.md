# Уроки інформатики 3–4

Календарно-тематичне планування на 2026/2027 і конспекти уроків інформатики для 3 і 4 класів НУШ.
Одна статична сторінка: клас → КТП → конспект уроку, плюс журнал проходження програми.

## Що всередині

| | 3 клас | 4 клас |
|---|---|---|
| Уроків у КТП | 32 | 32 |
| Детальних конспектів | 16 (уроки 1–16) | 16 (уроки 1–16) |
| Джерело КТП | складено на основі типової освітньої програми (Р. Б. Шиян, інформатична галузь) | наданий школою документ, автори Г. В. Ломаковська, Г. О. Проценко |

Уроки 17–32 показані як каркас: тема, очікувані результати, змістова лінія — без покрокового конспекту.

Кожен детальний конспект розрахований на 45 хвилин і тримає безперервну роботу за екраном у межах
15 хвилин — це вимога п. 7 Санітарного регламенту для закладів загальної середньої освіти
(наказ МОЗ № 2205 від 25.09.2020) для 2–4 класів.

## Журнал проходження

Позначки «проведено», фактичні дати й нотатки після уроку зберігаються в `localStorage` браузера —
без сервера й без облікових записів. Це означає, що вони прив'язані до одного браузера на одному
пристрої. Для перенесення на головній сторінці є **Експортувати журнал** / **Імпортувати журнал**
(файл JSON).

## Публікація через GitHub Pages

`index.html` лежить у корені й закомічений — Pages роздає його без жодної збірки на боці GitHub.

1. Settings → Pages → Source: **Deploy from a branch**
2. Branch: `main`, folder: `/ (root)` → Save
3. За хвилину-дві сторінка буде на `https://<user>.github.io/<repo>/`

Файл `.nojekyll` вимикає обробку Jekyll — вона тут не потрібна.

## Збірка

Сторінка збирається з шаблона й даних:

```
src/shell.html    розмітка, стилі та логіка; містить плейсхолдер __DATA__
src/ktp3.json     КТП 3 класу: тема, очікувані результати, змістова лінія
src/ktp4.json     КТП 4 класу, розібране з наданого PDF (разом з колонкою навчальної діяльності)
src/plans3.json   конспекти 3 класу
src/plans4.json   конспекти 4 класу
src/dates.json    дати уроків — понеділки від 07.09.2026 з урахуванням канікул
src/build.py      складає все це в index.html
```

Після зміни будь-якого JSON:

```bash
python3 src/build.py
```

Скрипт нічого не встановлює й не потребує залежностей — лише Python 3.

### Структура конспекту

```jsonc
{
  "n": 1,
  "goal": "мета уроку одним реченням",
  "equip": ["ПК на кожного учня", "проєктор"],
  "steps": [
    {
      "t": "00–04",              // проміжок часу
      "d": "4 хв",               // тривалість
      "h": "Заголовок етапу",
      "tag": "запис у журналі",  // необов'язкова позначка
      "b": ["пункт", "пункт"],   // що робимо; допускається інлайновий HTML
      "say": {"l": "Скажи класу", "t": "репліка"}  // необов'язкова врізка
    }
  ],
  "hw": "домашнє завдання"
}
```

Щоб додати конспект до уроку 17–32 — просто допиши об'єкт у відповідний `plansN.json`
і перезапусти збірку. Порядок у файлі не важливий, ключем є `n`.

## Дати

Розраховано на понеділки від 07.09.2026 з орієнтовними канікулами: осінні 26–30.10.2026,
зимові 28.12.2026 – 08.01.2027, весняні 22–26.03.2027. Це припущення, а не наказ школи.
08.03.2027 і 03.05.2027 припадають на святкові дні — звірте з наказом і виправте `src/dates.json`
або поставте фактичну дату в журналі.
