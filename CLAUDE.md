# CLAUDE.md

Статичний сайт з КТП і конспектами уроків інформатики для 3 і 4 класів НУШ,
2026/2027. Один учитель, один користувач. Українська — мова коду, даних і
спілкування в цьому репозиторії.

## Команди

```bash
python3 src/build.py     # збирає index.html із src/shell.html + src/*.json
```

Залежностей немає, лише Python 3. Тестів немає — перевірка це відкрити
`index.html` у браузері.

## Архітектура

Один самодостатній HTML-файл. Дані вшиваються в нього як `const DATA = {...}`
на місці плейсхолдера `__DATA__`.

```
src/shell.html    розмітка, CSS, JS; містить __DATA__, /*__WIN_CSS__*/, /*__WIN_JS__*/
src/win/          схема «Windows на проєктор»: *.js по порядку імен + win.css
src/ktp3.json     КТП 3 класу
src/ktp4.json     КТП 4 класу (розібране з PDF школи; колонка act не використовується)
src/plans3.json   конспекти 3 класу
src/plans4.json   конспекти 4 класу
src/calendar.json структура навчального року: межі, канікули, свята, день тижня
src/build.py      складання
index.html        згенерований файл, закомічений — його роздає GitHub Pages
```

**`index.html` руками не редагувати.** Правити `src/`, потім `python3 src/build.py`.
Обидва класи мають по 32 уроки; ключ уроку — поле `n` (1..32).

Дати уроків і межа семестрів руками не задаються — `build.py` рахує їх із
`src/calendar.json` і кладе у `DATA.dates` та `DATA.s2` (номер першого уроку
ІІ семестру). Змінився наказ школи — правиться лише `calendar.json`.

Журнал проходження (проведено / фактична дата / нотатки) зберігається в
`localStorage` під ключем `uroky-inf-3-4`. Сервера немає.

Кнопка «Експортувати бекап» на головній складає JSON з усім поточним станом:
журнал (проведено, фактична дата, нотатка — зокрема й по не проведених уроках)
плюс знімок `DATA`, тобто КТП, конспекти, дати й `s2`. Імпорт бере з файлу лише
журнал; контент там лежить як архів, а не як спосіб підмінити зібраний сайт.
Формат — `v:2`; файли `v:1` (без `data`) імпортуються так само.

## Жорсткі обмеження для будь-якого нового конспекту

1. **Безперервна робота за екраном ≤ 15 хв** — п. 7 Санітарного регламенту
   (наказ МОЗ № 2205 від 25.09.2020) для 2–4 класів. Практична частина
   планується на 11–14 хв, не більше. Це не рекомендація.
2. **Урок 45 хв**, сума таймінгів має сходитися рівно.
3. **Гімнастика для очей 2 хв** обов'язкова перед практичною роботою.
4. **Домашні завдання в початковій школі не задаємо.** Поле `hw` — або
   «Не задаємо», або необов'язкове завдання без перевірки.
5. **Оцінювання вербальне та рівневе**, не бальне. Конспекти не містять
   виставляння оцінок.
6. ПК на кожного учня (або один на двох), є проєктор.

## Схема конспекту

```jsonc
{
  "n": 1,
  "goal": "мета одним реченням",
  "equip": ["ПК на кожного учня", "проєктор"],
  "steps": [
    { "t": "00–04", "d": "4 хв", "h": "Заголовок етапу",
      "tag": "запис у журналі",            // необов'язково; «журнал» → червона позначка
      "b": ["що робимо", "що робимо"],     // допускається інлайновий HTML
      "say": {"l": "Скажи класу", "t": "репліка"},    // необов'язкова врізка
      "show": "keyboard" }   // необов'язково; кнопка «на проєктор», див. нижче
  ],
  "hw": "Не задаємо."
}
```

Поле `show` додає в етап кнопку, що відкриває повноекранну схему для проєктора.
Схеми зареєстровані в `SHOWS` у `src/shell.html`.

`"keyboard"` — повнорозмірна клавіатура з українськими й
англійськими літерами, розфарбована за п'ятьма групами (літери і знаки, цифри,
функціональні, спеціальні, стрілки). `"keyboard:<пресет>"` відкриває її одразу
з підсвіченою комбінацією: `five`, `caps`, `bsdel`, `win`, `alt` (або назва
групи: `let`, `num`, `fn`, `ctl`, `nav`). Поки схема відкрита, натискання на
клавіатурі ПК учителя підсвічують ту саму клавішу й показують надрукований
символ. Під схемою — поле на всю ширину, куди друкується натиснуте: власний
маленький редактор (`kbTypeKey`), не textarea, бо потрібні товстий курсор і
«привид» стертої літери з того боку курсора, звідки її прибрали. Працює як
Блокнот: стрілки, Home/End, Shift-виділення, Ctrl + стрілки, Ctrl + A/C/X/V/Z,
Insert — режим заміни. Код — у `src/shell.html`, блок `KB_*` / `kbOpen`.

`"windows"` — навчальна копія Windows 10 і 11 (перемикач над екраном;
`"windows:10"` / `"windows:11"` відкривають одразу потрібну). Без навчальних
надбудов: лише те, що є в справжній Windows, — шлях учитель показує рядком
адреси, тип файлу — стовпцем «Тип» і «Властивостями». Починається з робочого
столу: Кошик і теки класів, як у школі, — частина на Робочому столі (3А, 4А,
5А–7А), частина в Документах (3Б, 4Б, 8А–11А), усередині папки учнів
«Прізвище Ім'я»; «Цей ПК» → шість папок користувача й диски C: (Windows,
програми, Користувачі) і D: (архів, фото).
Провідник відкривається через «Пуск» (пошук, у 10 — «Службові — Windows»,
у 11 — закріплені й «Усі програми»), жовту папку на панелі завдань, Win + E,
Win + X, подвійне клацання теки на столі. Провідник 10 — зі стрічкою, 11 — з
вкладками й панеллю команд; дерево, рядок адреси (клацання — адреса текстом
`C:\Users\Учень\Desktop\…`, можна ввести шлях), пошук, вісім виглядів, сортування,
панелі відомостей і перегляду, «Властивості».
З файлами й папками — як у Windows: створення (меню, стрічка, Ctrl + Shift + N),
перейменування (F2, меню, повільне друге клацання), Delete у Кошик і відновлення,
Shift + Delete, Ctrl + C / X / V, перетягування мишею (у межах диска — переміщення,
між C: і D: — копія, з підписом біля вказівника), рамка виділення. Правила Windows:
заборонені символи не друкуються й з'являється підказка; однакове ім'я в папці —
діалог з пропозицією «(2)»; зміна розширення — попередження; при схованих
розширеннях «Кіт.png» у документа Word стає «Кіт.png.docx»; системні папки й диски
не перейменовуються й не видаляються; Program Files, Windows і Користувачі вимагають
прав адміністратора. Файли відкриваються в імітаціях Блокнота (редагується;
«Зберегти» / Ctrl + S у файлу з ім'ям зберігає мовчки, як у Windows, а «Зберегти як…» /
Ctrl + Shift + S і новий файл «Без назви» відкривають вікно збереження з деревом,
адресою, «Новою папкою», іменем і типом файлу; питання про збереження при закритті), Фотографій, Word, PowerPoint, Paint,
медіапрогравача, Edge.
Мова схеми своя (УКР / ENG): перемикається кліком на індикатор біля годинника,
Win + Пробіл і Alt + Shift, і все, що друкується в полях схеми, йде за нею по коду
клавіші (`WN_KEYS`, `wnChar`), а не за розкладкою ПК учителя.
Клавішу Win браузер віддає сторінці лише в режимі «На весь екран» через Keyboard
Lock (Chrome, Edge) — тоді працюють Win, Win + E, Win + D, Alt + F4; поза ним є
кнопка «Win + E». «Показувати клавіші» виводить натиснуту комбінацію внизу екрана.
Екран малюється у віртуальних 1366×768 (або 1093×614 з «Крупніше») і
масштабується цілком. Усе живе лише в пам'яті сторінки, «Скинути» повертає
початковий стан.
Код — `src/win/`: `10-model.js` (дерево, операції, вікна), `20-icons.js` (значки,
шпалери), `30-view.js` (розмітка), `40-input.js` (миша, клавіатура, меню,
`wnOpen`), `win.css`. `build.py` вшиває їх у `index.html` на місце
`/*__WIN_CSS__*/` і `/*__WIN_JS__*/` у `src/shell.html`. Класи сайту (`.row`,
`.bar`, `.nav`…) глобальні — нові класи в схемі перевіряй на збіг.

Типова структура 45 хв: організація 3 → актуалізація 7–10 → нове 10–14 →
гімнастика 2 → практична 11–14 → підсумок 6–7.

## Як писати конспекти

Аудиторія — учитель, який читає це з телефона під час уроку. Тому:

- конкретні дії, а не методичні формулювання: «пройди рядами і поправ посадку»,
  а не «здійснити індивідуальний підхід»;
- називати типові помилки дітей до того, як вони стануться, і що казати вголос;
- обмеження в практичних завданнях навмисні (наприклад «лише три інструменти») —
  вони тренують конкретну навичку, не прибирати їх «для свободи творчості»;
- кожен блок практичної закінчується явним збереженням файлу з іменем за схемою
  `Прізвище_щось`;
- без емодзі, без вигуків, без мотиваційних вставок.

## Джерела КТП і що з ними не так

- **4 клас** — наданий школою документ (типова освітня програма під керівництвом
  Р. Б. Шияна; автори Г. В. Ломаковська, Г. О. Проценко). Теми й очікувані
  результати з індексами ТОП взяті звідти дослівно. Не переписувати теми.
- **3 клас** — школа підтвердила, що клас іде за тією ж програмою Шияна. Сам КТП
  складено з нуля й узгоджено з логікою 4 класу. **Не затверджений школою.**
  Це робочий документ.
- **Дати** — понеділки за наданою школою структурою року: 01.09.2026 — 04.06.2027,
  канікули осінні 26–30.10.2026, зимові 24.12.2026 — 08.01.2027, весняні
  22–26.03.2027, великодні 30.04 — 03.05.2027. 08.03.2027 (свято) виключено.
  Виходить 07.09.2026 — 24.05.2027, у запасі один понеділок 31.05.2027.
- **Семестри** — І закінчується уроком 15 (21.12.2026), ІІ починається уроком 16
  (11.01.2027). Тобто 15 і 17 уроків, а не 16 і 16. Підсумок семестру в 3 класі —
  на уроці 15; урок 16 це вже перший урок після канікул.

Стан на момент створення репозиторію: детальні конспекти є для уроків 1–16
обох класів, уроки 17–32 показані як каркас (тема, очікувані результати,
змістова лінія).

## Вивантаження в НІТ

На сторінці КТП кожного класу, під фільтрами семестрів, є кнопка «Завантажити
файл для НІТ» — вона збирає `.xlsx` для цього класу прямо в браузері (генератор
у `src/shell.html`: `crc32`, `zipStore`, `xlsxOneColumn`, `downloadNit`; zip без
стиснення, бібліотек немає).

Формат узято зі шаблону НІТ і він гранично простий: одна книга, аркуш
**«План навчання»**, єдиний стовпець A. `A1` — заголовок **«Зміст робіт»**,
далі по рядку на урок, тобто `A2..A33` — 32 теми в порядку `n`. Ні дат, ні
номерів уроків, ні домашнього завдання у файлі немає: НІТ розставляє дати сам
за розкладом, а прив'язка до уроку — це порядок рядків. У колонку йде дослівно
поле `topic` з `ktp3.json` / `ktp4.json`, без нумерації й без очікуваних
результатів.

Кнопка експортує рівно те, що зараз показує фільтр семестрів, — перелік уроків
для списку й для файлу дає одна функція `ktpNums()`, щоб екран і файл не могли
розійтися. Фільтр потрапляє і в ім'я файлу (`Інформатика-4-клас-І-семестр.xlsx`),
і в кількість тем на самій кнопці.

Змінилися теми в КТП — просто натиснути кнопку ще раз і перезавантажити план
у НІТ. Готові `.xlsx` у репозиторії не зберігаються.

## Дві копії, які розходяться

Той самий сайт існує у двох місцях:

- **GitHub Pages** — цей репозиторій, журнал у localStorage браузера;
- **артефакт на claude.ai** — окрема копія, журнал на сервері.

Вони не синхронізуються. Джерело правди для контенту — цей репозиторій.
Якщо змінюється конспект, артефакт треба перепубліковувати вручну, інакше
розійдуться.
